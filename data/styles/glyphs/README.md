# Glifos y Fuentes Vectoriales

Este directorio alberga los archivos `.pbf` de fuentes tipográficas para renderizado de etiquetas en MapLibre.
Se pueden generar o descargar fuentes compatibles como Noto Sans / Roboto desde OpenMapTiles Fonts:
https://github.com/openmaptiles/fonts
